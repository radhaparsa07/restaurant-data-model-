# Restaurant Data Model

This project contains a logical and physical data model for a restaurant business that plans to expand into franchise locations and food trucks.

## Data Model

The model includes the following main entities:

- Customer
- Orders
- Order Items
- Menu Items
- Locations
- Employees
- Payments
- Ingredients
- Inventory

The model defines the primary keys, foreign keys, relationships, and data types for the tables.

The `location` table supports different types of locations, including restaurants and food trucks, and includes a franchise flag to support future franchise expansion.

The model is designed to support restaurant operations and future data analysis around customers, sales, locations, employees, menu items, and inventory.
